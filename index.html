App Builder (Windows & Android)

Turn this OmniTool single-file web app into native Windows (.exe) and Android (.apk) applications using GitHub.

1. Build for Windows (Electron)

1 Setup Repository

Save this HTML code as index.html in a new GitHub repo.

2 Add Core Files

Add the main.js and package.json files below to the repo root.

main.js 
const { app, BrowserWindow } = require('electron');
const path = require('path');
function createWindow() {
    const mainWindow = new BrowserWindow({
        width: 1280, height: 800, title: "OmniTool",
        webPreferences: { webviewTag: true, nodeIntegration: true, contextIsolation: false }
    });
    mainWindow.loadFile(path.join(__dirname, 'index.html'));
}
app.whenReady().then(createWindow);
app.on('window-all-closed', () => { if (process.platform !== 'darwin') app.quit(); });
package.json 
{
  "name": "omnitool", "main": "main.js",
  "scripts": { "start": "electron .", "build": "electron-builder -w" },
  "devDependencies": { "electron": "^28.0.0", "electron-builder": "^24.6.4" }
}

Run npm install then npm run build locally, or use GitHub Actions.

2. Build for Android (Capacitor)

1 Folder Setup

Place index.html inside a folder named www in your repo.

2 Dependencies

Add the package.json and config files below.

3 Compile

Run npx cap add android then build with Android Studio.

capacitor.config.json 
{
  "appId": "com.omnitool.app",
  "appName": "OmniTool",
  "webDir": "www",
  "bundledWebRuntime": false
}
package.json (Android root) 
{
  "name": "omnitool-android",
  "dependencies": {
    "@capacitor/android": "^5.0.0",
    "@capacitor/core": "^5.0.0"
  },
  "devDependencies": {
    "@capacitor/cli": "^5.0.0"
  }
}

3. Automate in GitHub Actions

To automatically build these apps every time you push code to GitHub, create a folder called .github/workflows/ in your repo. Inside, add a file named build.yml to run electron-builder for Windows, or use ionic-team/capacitor-build-action for Android APKs. GitHub will generate the downloadable .exe and .apk files straight to your repository's Actions tab!
